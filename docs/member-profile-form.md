# HPC Lab 成員資料與頭像

正式入口是網站的 `/member/me`，適用碩一、碩二及實驗室畢業學長姊。管理者在 `/admin/members` 以姓名、信箱、身分建立一次性邀請，再自行將連結交給本人；網站不開放自行註冊。邀請有效 30 天，啟用及重設密碼至少 10 字元。管理者核對身分後可產生有效一小時的一次性重設連結。

成員登入後自行編輯中文與英文姓名、入學或畢業年度、學位、研究方向、簡介、目前單位及個人連結。畢業成員必須從下拉選單選西元畢業年份與上／下學期；公開卡片只顯示「2026年‧上畢業」這類標示，不重複顯示「實驗室畢業學長姊」。舊資料若只有年份，暫顯示「2026年畢業」，待本人補選學期，不擅自推定。公開與否由成員勾選並儲存，**不經人工審核**：同意公開時，資料立即寫入 `/people` 的公開名單；取消公開時，立即從公開 API 移除。頭像有獨立的公開同意勾選，未同意時只供本人及管理者檢視。管理者仍可在必要時緊急撤下；此狀態需由管理者恢復。

「學歷與經歷」可由本人新增、排序、刪除最多 8 筆，每筆填學歷／經歷類型、學校或單位、科系或職稱，以及選填期間。名單上的卡片只顯示摘要；點入 `/people/:id` 才看完整簡介、學歷經歷、研究方向與個人連結。這些欄位隨公開同意一起刊登，撤回公開時詳情頁也不再顯示。彰化高工電子科、高雄科技大學等例子只作表單提示，不會替任何人預填或刊登。

頭像入口在 `/member/me` 的「網站展示」→「頭像照片」→「選擇照片並裁切」。成員可拖動方框、拖曳右下角或使用滑桿調整正方形裁切範圍；確認預覽後，按表單底部的儲存按鈕才會上傳。原圖限 JPEG、PNG、WebP、5 MB，長寬至少 200 像素。瀏覽器只送出裁切後的 640×640 圖片，後端再次驗證、轉為 WebP 並移除原始中繼資料。未上傳頭像時，公開頁顯示姓名縮寫。

公開 API 只傳顯示姓名、身分、年度、學位、研究標籤、簡介、學歷經歷、單位、個人連結及經本人同意的頭像網址，不含信箱、密碼、邀請 token 或同意欄位。個人連結只接受 `https://`；所有公開文字在服務端限制長度，頁面由 React 轉義。公開頭像網址包含更新時間版本，換照片後瀏覽器可取得新檔。

成員資料與頭像存於獨立的 SQLite PVC，網站的兩個副本只代理 API。首次部署此免審核流程時，原先狀態為 `pending` 且已有公開同意的資料會自動轉為公開；被管理者撤下的 `hidden` 資料不會自動恢復。身分變更後原公開資料先撤下，成員補齊新身分的必填欄位並儲存後可自行重新公開。部署與備份方式見[網站架構](website-architecture.md)。
